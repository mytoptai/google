Privacy Policy

MyRclone

Last updated: October 11, 2026

1. Overview

MyRclone is a personal, non-commercial application that integrates with Google Drive using OAuth 2.0 and the Google Drive API.

2. Data Access

With the user's authorization, the application may access Google Drive files, folder information, file metadata, and file contents, depending on the permissions granted.

File modifications, uploads, and deletions are performed only when supported by the granted permissions and requested or configured by the user.

3. Data Usage

Google Drive data is used solely to provide file management, synchronization, upload, and download functionality.

Google user data is not used for advertising, profiling, or unrelated purposes.

4. Data Storage

OAuth credentials and authentication tokens are stored locally on the user's device through rclone configuration.

Downloaded or synchronized files are stored in locations configured by the user.

MyRclone does not operate a separate cloud database for storing Google Drive user data.

5. Data Sharing

MyRclone does not sell Google user data. File operations communicate with Google Drive through the Google Drive API.

Google Drive contents and OAuth tokens are not sent to an application-operated analytics or advertising service.

6. Security

OAuth 2.0 is used for Google authorization. API communication uses HTTPS.

Users are responsible for protecting their local authentication configuration and files.

7. Revoking Access and Deleting Data

Users can revoke application access through their Google Account settings:

Google Account - Third-party connections

Users may also remove their local rclone configuration, authentication tokens, and downloaded files.
