MyRclone

Personal Google Drive Integration Utility

About

MyRclone is a personal, non-commercial utility designed to access and manage Google Drive files using the Google Drive API and OAuth 2.0.

This application is intended for personal use and is not offered as a public service.

Features

  • Browse Google Drive files and folders
  • View file metadata
  • Upload and download files
  • Synchronize local files with Google Drive
  • Manage files with user authorization

Google Drive Integration

MyRclone uses OAuth 2.0 to obtain permission from the Google account owner.

Google Drive data is accessed only for functionality explicitly initiated or configured by the user.

Authentication and file operations are handled locally through rclone.
